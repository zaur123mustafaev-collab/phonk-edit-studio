# Phonk Edit Studio — плагин и скилл для Claude

Claude делает TikTok / Reels эдиты из твоего клипа: сам обрезает рамки и надписи клип-паков, режет под бит,
ставит переходы и эффекты, накладывает твою вотермарку и подбирает музыку.

## Что умеет
- **Автообрезка**: убирает серые рамки, чёрные полосы и надписи вроде «4K CLIPS FOR EDITS» / «FOLLOW FOR MORE».
- **Монтаж под бит**: находит биты и дроп, ставит лучшие (самые динамичные) шоты на дроп, темп 0,6–1,2 с на шот.
- **Переходы**: вспышка, zoom blur, whip, круг с кольцом, картинка-в-картинке, глитч, тряска, RGB, вылет в кружок в конце.
- **Эффекты**: velocity, зум и тряска на ударах, лёгкое свечение и зерно, чёткое увеличение картинки.
- **Вотермарки** (анимация показывается ровно один раз — если в записи она повторяется, плагин сам вырезает один цикл):
  - маленькая полупрозрачная **всё видео** (картинка, текст или логотип, вырезанный из твоего видео-интро);
  - твоя **анимированная вотермарка-видео** (например, интро из CapCut, даже запись экрана): один раз, по центру, без звука.
- **Музыка**:
  1. твой трек, если прислал;
  2. фонк, который уже есть в клипе;
  3. если музыки нет — Claude **генерирует свой оригинальный фонк** (коубелл, 808, хэты), без проблем с авторскими правами.
- **Эдиты с разговором**: распознаёт речь, вставляет фразу между интро и дропом, губы совпадают со звуком.

## Установка

### Claude Code (через плагин)
В Claude Code выполни:
```
/plugin marketplace add zaur123mustafaev-collab/phonk-edit-studio
/plugin install phonk-edit-studio@phonk-edit-studio-marketplace
```
Потом просто напиши: «сделай эдит» и прикрепи клип, или используй команду `/edit`.

### Claude (приложение / сайт) — как навык
Загрузи архив `dist/tiktok-edit-skill.zip` в настройках Claude, раздел навыков (Skills), если он доступен на твоём тарифе.
После этого в любом чате можно прислать клип и написать «сделай эдит».

### Что нужно на компьютере (для Claude Code)
- Python 3.10+ и ffmpeg (Windows: `winget install Gyan.FFmpeg`).
- Библиотеки ставятся сами: `python skills/tiktok-edit/scripts/check_env.py`.
- Для эдитов с разговором дополнительно: `pip install faster-whisper`.

## Как пользоваться
1. Скачай клип (например, через ssstik) и прикрепи файлом. Ссылки на TikTok Claude скачать не может.
2. Прикрепи вотермарку: картинку, текст («поставь ник MYNAME») или видео-интро.
3. По желанию прикрепи трек (mp3) и напиши пожелания: длина, «помедленнее», «больше эффектов», «с разговором».
4. Claude покажет план и превью кадров, отрендерит видео и проверит его перед отправкой.

Рендер 1080×1080 / 60 fps занимает несколько минут: примерно 15–20 секунд на каждую секунду видео на двух ядрах.

## Ограничения
- Claude не слышит звук: биты и дроп он находит анализом. Проверь синхронизацию и скажи, если что-то поправить.
- Не генерирует видео нейросетью и не скачивает песни из интернета.
- Если исходник маленький (640 px и меньше), до настоящего 1080p картинка не дотянет.
